## Runtime and Focus Limits

Current canonical iris radius is **15.228704085 mm**, derived from source f/1.25; older 15.44 mm runtime prose is superseded. The original publishes no numerical physical stop radius. At infinity the current exact working value is **f/1.268472**, distinct from the nominal/paraxial convention. The source-station aperture and image-circle audits pass, and the generic full-frame chief reaches **21.65 mm** at about 23.1°. A geometry-identical 21-position focus sweep at the current iris uses **12,159 collimated rays per version** (193 pupil samples × three fields × 21 controls). All 4,053 axial samples and all 63 chiefs pass; off-axis vignetting remains. Infinity/close bundles are **193/150/84** and **193/161/110** at axial/half/corner field. Counts are identical before and after this review. This control sweep is collimated where the data declares no numerical source finite conjugate; it is not a finite-focus certification.

A separate Gaussian finite-conjugate supplement derives each real object plane from the literal current paraxial matrix, then solves its chief to the generic 21.65 mm image-height edge. Across **20 non-infinity controls and 11,580 rays**, all **60 chiefs** pass with zero unaimed or failed intersections. Of **3,860 axial samples**, **3,716 pass**: at focus 0.75–1.00 the outer24/193 clip S17, leaving169/193. Closest-focus bundles are **169/159/100**.
