## Optical architecture and element analysis
Four actual bodies are L1 singlet, L2/L3 cemented pair, L4 singlet, and L5/L6 cemented pair. Both cemented interfaces and all source air separations are retained. L1 is a positive meniscus with nD1.6909/V54.9. L2 has the same nD/V, while its cemented L3 uses1.6227/36. L4 is the negative singlet with1.6535/33.5. Rear cemented L5/L6 use1.6909/54.9 and1.5890/61.4 respectively. These are literal source data, not named modern glass replacements.

High-resolution reinspection confirms both EI and EII print V61.4 for nD1.5890. An earlier research report misread EI as51.4; that claim is superseded, not a genuine source discrepancy. EII's numerical model was already61.4 and did not change. Matching nD/V does not prove an identical historical glass melt. The patent explicitly defines D-line index and Abbe V. The runtime d-line reference approximates historical D; no measured full spectral curve, exact historical melt or manufacturing tolerance is claimed.
