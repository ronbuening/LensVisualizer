The previously uncertain drawing readings must not be used as alternate source values. Table source selection is explicit, not a silent repair.

## Optical Architecture

Four elements in two cemented positive achromats, separated by94.54mm. Each is biconvex crown followed by plano-concave flint in the model's screen-to-film direction. Front radii are±82.57mm; rear radii±41.28mm. The patent's normal projection travels film-to-screen, opposite model direction. This model represents the reciprocal infinity-conjugate limit, not a validated finite theater projection setup.

## Element-by-Element Analysis

### Front doublet A: L1 and L2

L1: nD=1.5160, νD=63.8, borosilicate-crown class,8.54mm thick. L2: nD=1.6182, νD=36.4, dense-flint class,2.85mm thick. The common curved cemented interface is−82.57mm and the exit face is flat. These are source glass constants, not identified modern catalog glasses.

### Rear doublet B: L3 and L4

L3 and L4 repeat the table glass constants and respective8.54/2.85mm center thicknesses, with±41.28mm curved surfaces and a final plane. No claimed thin air spacing variant is introduced: this is the table's cemented embodiment.

## Aperture and Field Qualifications

The source states45.4mm free diameter of the front group. An equivalent front aperture limiter is represented at the front-vertex plane; this is not an asserted physical iris. Nominal f/2.2 is rounded: computed EFL divided by45.4 gives model f/2.202566. Only that fixed aperture is exposed.

Front-group semi-diameters are22.7mm. Rear semi-diameter17.5mm is a provisional model estimate: a meridional sample through±3° reached16.2189mm on the rear group; adding5% and rounding up to0.5mm gives17.5mm. It is NOT a measured factory barrel aperture. ±3° is a diagnostic field choice, not source image-circle coverage. No camera mount or film format is asserted.
