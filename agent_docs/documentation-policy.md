# Documentation Policy

Document what an agent needs to work today and nothing that git, the PR, the changelog, or a generated report already
holds. Every living doc under `agent_docs/` appears once in `agent_docs/README.md` with a tag; `__tests__/docDrift.test.ts`
enforces the rules marked *(guarded)*.

## Where things go

| If you…                                                   | Write it in                                                                 |
| --------------------------------------------------------- | --------------------------------------------------------------------------- |
| change how a subsystem works                              | `agent_docs/architecture/` — replace the stale text, no dates or PR narrative |
| add a repeatable change type                              | an `adding_<thing>.md` recipe; field semantics go in `src/**/*_SPEC.md`       |
| decide not to do something, or verify something is fine   | `agent_docs/decisions.md` — one dated bullet with a source pointer            |
| hit a non-obvious failure mode                            | `agent_docs/gotchas.md` — one bullet plus a pointer, never a restated procedure |
| open follow-up work                                       | the matching `[queue]` doc, or `FEATURE_ADDITION_PLAN.md`                     |
| audit a lens against its patent                           | the lens's `*.audit.md` sidecar, per `agent_docs/lens-patent-audit.md`        |
| ship a user-visible change                                | `src/utils/content/changelogData.ts`, per `agent_docs/changelog.md`           |
| finish a branch                                           | the PR description — not a file under `agent_docs/records/`                   |

## What is not documented

- Verification transcripts, pass counts, command output, or timing logs.
- Completed checklist rows, "done" sections, phase-by-phase histories, or landed-PR narratives.
- Anything `git log`, the PR, or the changelog already records.
- Regenerable content: `agent_docs/generated/` and `src/**/readme.md` are rewritten by scripts — regenerate, never hand-edit
  (the only hand-written file there is the reviewed Sellmeier sidecar named in `agent_docs/README.md`).
- The same rule in two places. One doc owns a rule; every other doc points to it with a single line.

## Retention triggers

| Artifact                         | Trigger                                                                                   |
| -------------------------------- | ----------------------------------------------------------------------------------------- |
| `[queue]` row                    | delete when done, in the same commit that closes it                                       |
| `[queue]` plan                   | delete when 100 % closed, after moving its "do not rebuild / do not fix" items to `agent_docs/decisions.md` |
| `[record]`                       | delete at merge unless a living doc or a `*.audit.md` sidecar links it *(guarded)*         |
| `*.audit.md` sidecar             | when it passes ~200 lines, squash older sessions into "Historical audits prior to <date>" (`agent_docs/lens-patent-audit.md`) |
| `[architecture]` / `[recipe]`    | fix stale names in place; a doc that only restates another doc is deleted                  |
| generated reports and benchmarks | regenerated by their scripts; retention is decided in `agent_docs/README.md`, not per file  |

## CLAUDE.md and AGENTS.md

- At most 200 lines *(guarded)*; `AGENTS.md` is a byte copy of `CLAUDE.md` *(guarded)* — run `cp CLAUDE.md AGENTS.md`.
- Pointers, not copies: route to the doc that owns a rule instead of restating it.
- No code snippets, no generic advice, nothing the agent already does correctly without being told.
- Every "do not" is paired with the preferred alternative.
- The Commands fence lists the day-to-day subset; `agent_docs/workflow.md` carries the full script inventory *(guarded)*.
- The Project Map lists top-level directories; `agent_docs/architecture.md` carries the full tree *(guarded)*.

## Index rules

- `agent_docs/README.md` lists every doc under `agent_docs/`, `agent_docs/architecture/`, and `agent_docs/records/`
  exactly once, each entry starting with one tag *(guarded)*:
  `[policy]` how we work · `[recipe]` steps for one change type · `[architecture]` how the code works now ·
  `[queue]` open work only · `[record]` linked historical or in-progress notes · `[generated]` regenerable reports.
- Update the index in the same commit as any add, delete, or rename; the tests fail otherwise.
- Do not add subfolders for tiers. `CONTRIBUTING.md`, `README.md`, and hundreds of `*.audit.md` sidecars link the flat
  recipe paths; tags carry the tier.
